# Online Strategy for Contact Fault Diagnosis in Power Transformers

## Paper information

-   **Manuscript ID:** 10772
-   **Title:** *Online Strategy for Contact Fault Diagnosis in Power
    Transformers*
-   **Authors:** Lucas Puntano, Gustavo Leal, Matias Meira, Cristian
    Ruschetti, and Carlos Verucchi
-   **Affiliation:** CIFICEN (CONICET--CIC--UNICEN), Sede Olavarría,

## Overview

This repository is intended to provide the MATLAB code associated with
the paper *Online Strategy for Contact Fault Diagnosis in Power
Transformers*.
