## Overview

This repository is intended to provide the MATLAB code associated with
the paper *Online Strategy for Contact Fault Diagnosis in Power
Transformers* and to document how to reproduce the results reported in
the manuscript.

**Important:** The experimental data used in the paper cannot be made
publicly available. Therefore, complete reproduction of the published
results may require access to those data. The repository maintainers
should specify whether any permitted example data, processed data, or
